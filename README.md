# Ron Teaching

HTML teaching materials from the Brenner teaching project.

Original OneDrive files remain the canonical editable copies. Class folders are preserved within each category.

Download the repository and open an HTML file in a browser to view or print it.

## Folders

- `worksheets/`: worksheets and their separate solution versions.
- `helper-sheets/`: concept summaries and reference sheets.
- `interactive-apps/`: interactive teaching applications and dashboards.
- `assessment-tools/`: grading rubrics and printable marking guides.
- `reports/`: aggregate teaching reports.

The source folders `calc_project` and `תבניות` are excluded from publication, including future updates.
