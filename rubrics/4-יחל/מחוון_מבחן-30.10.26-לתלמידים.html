שאלה 1

חקירת פונקציה רציונלית והזזה

שאלה 1 · צמצוםפתיחה

א תחום הגדרה

x ≠ 2

פתרון: המכנה חייב להיות שונה מאפס: x − 2 ≠ 0.

אין הגבלה מהמונה: הוא יכול להיות אפס. ההגבלה היחידה כאן נובעת מחילוק באפס במכנה.

ב אסימפטוטה אנכית

x = 2

בהצבת x = 2 המכנה שווה 2 − 2 = 0, והמונה שווה 2² − 6·2 + 9 = 1. לכן הפונקציה אינה מוגדרת שם. כאשר x מתקרב ל־2, המכנה מתקרב לאפס ואילו המונה מתקרב ל־1, ולכן ערכי הפונקציה גדלים בגודלם ללא חסם. מכאן שהישר x = 2 הוא אסימפטוטה אנכית.

ג חיתוך עם הצירים

(3, 0) ; (0, −4.5)

על כל ציר אחד השיעורים שווה לאפס: על ציר x מתקיים y = 0, ועל ציר y מתקיים x = 0.

חיתוך עם ציר x: מציבים f(x) = 0. שבר שווה לאפס כאשר המונה אפס והמכנה אינו אפס:

(x − 3)² = 0 ⇒ x = 3

הערך 3 בתחום ההגדרה, ולכן נקודת החיתוך היא (3, 0).

חיתוך עם ציר y: מציבים x = 0 בפונקציה:

f(0) = 0² − 6·0 + 90 − 2 = 9−2 = −4.5

לכן נקודת החיתוך היא (0, −4.5).

ד נקודות קיצון וסוגן

מקסימום (1, −4); מינימום (3, 0)

בניית הנגזרת: הפונקציה היא מנה. בכלל המנה הבא f(x) ו־g(x) הם שמות כלליים למונה ולמכנה:

(f(x)g(x))′ = f′(x)·g(x) − f(x)·g′(x)[g(x)]²

כאן המונה הוא x² − 6x + 9 ונגזרתו 2x − 6; המכנה הוא x − 2 ונגזרתו 1. מציבים בכלל המנה:

f′(x) = (2x − 6)(x − 2) − (x² − 6x + 9)·1(x − 2)²

פותחים סוגריים ומכנסים איברים במונה:

(2x − 6)(x − 2) − (x² − 6x + 9) = x² − 4x + 3 = (x − 1)(x − 3)
f′(x) = (x − 1)(x − 3)(x − 2)²

ערכים חשודים: פותרים f′(x) = 0 ומקבלים x = 1 או x = 3. המכנה בריבוע חיובי בכל תחום ההגדרה, ולכן הסימן נקבע על ידי המונה. בטבלה בוחרים ערך בדיקה מכל תחום ומציבים אותו בנגזרת.

סוג ושיעורים: ב־x = 1 הסימן משתנה מחיובי לשלילי, ולכן זה מקסימום; f(1) = −4. ב־x = 3 הסימן משתנה משלילי לחיובי, ולכן זה מינימום; f(3) = 0.

ה תחומי עלייה וירידה

עלייה: x < 1 או x > 3; ירידה: 1 < x < 2 או 2 < x < 3

הנגזרת בנקודה נותנת את שיפוע המשיק לגרף. שיפוע חיובי מעיד על עלייה כאשר מתקדמים ימינה, ושיפוע שלילי מעיד על ירידה. לכן תחומי העלייה הם התחומים שבהם f′(x) > 0, ותחומי הירידה הם התחומים שבהם f′(x) < 0.

לפי טבלת הסימנים, הפונקציה עולה כאשר x < 1 או x > 3, ויורדת כאשר 1 < x < 2 או 2 < x < 3. מפרידים בנקודה x = 2 משום שאינה בתחום ההגדרה.

ו(1) קיצון של הפונקציה המוזזת

מקסימום (1, 0); מינימום (3, 4)

פתרון: g(x) = f(x) + 4 היא הזזה של הגרף למעלה ב־4. ערכי x וסוגי הקיצון נשמרים; לכל ערך y מוסיפים 4.

למשל, נקודת המקסימום המקורית (1, −4) עוברת לנקודה (1, −4 + 4) = (1, 0). באותו אופן מתקבלת נקודת המינימום (3, 0 + 4) = (3, 4).

ו(2) מפגש יחיד עם ישר אופקי

k = 0 או k = 4

פתרון: טווח הענף השמאלי הוא y ≤ 0 וטווח הענף הימני הוא y ≥ 4. בגובה 0 ובגובה 4 מתקבלת נקודת מפגש יחידה, בנקודת קיצון. מתחת ל־0 או מעל 4 יש שני מפגשים; בין 0 ל־4 אין מפגשים. מפגש יחיד כולל השקה.

לכן לא מספיק לדעת שהישר עובר בגובה של נקודת קיצון: צריך לבדוק שאינו פוגש גם את הענף האחר. כאן טווחי שני הענפים נפרדים, ולכן בכל אחד משני הגבהים מתקבל מפגש יחיד בלבד.

שאלה 2

משיק והתנהגות פונקציה רציונלית

שאלה 2 · צמצוםפתיחה

א נקודת ההשקה

(4, 2)

פתרון: f(4) = 4 + 22·4 − 5 = 2.

ערך x של נקודת ההשקה נתון. כדי להשלים את הזוג הסדור מציבים אותו בפונקציה ומחשבים את ערך y.

ב שיפוע המשיק

m = −1

שיפוע המשיק שווה לערך הנגזרת בנקודת ההשקה. נשתמש בכלל המנה, כאשר f(x) מסמן באופן כללי את המונה ו־g(x) את המכנה:

(f(x)g(x))′ = f′(x)·g(x) − f(x)·g′(x)[g(x)]²

המונה כאן הוא x + 2 ונגזרתו 1; המכנה הוא 2x − 5 ונגזרתו 2. לכן:

f′(x) = 1·(2x − 5) − (x + 2)·2(2x − 5)²

מציבים את שיעור x של נקודת ההשקה:

f′(4) = 1·(8 − 5) − (4 + 2)·2(8 − 5)² = 3 − 129 = −1

ג משוואת המשיק

y = −x + 6

פתרון: y − 2 = −1(x − 4), ומכאן y = −x + 6. אפשר להשאיר את המשוואה גם בצורה השקולה שלפני הפישוט.

משוואת ישר ששיפועו m ועובר בנקודה (x₀, y₀) היא y − y₀ = m(x − x₀). מציבים m = −1 ואת הנקודה (4, 2).

ד תחום הגדרה

x ≠ 2.5

פתרון: 2x − 5 ≠ 0, ולכן x ≠ 2.5.

פותרים 2x − 5 = 0 ⇒ x = 52 ומוציאים ערך זה מתחום ההגדרה.

ה היעדר נקודות קיצון

אין נקודות קיצון.

בנקודת קיצון פנימית שבה הפונקציה גזירה, הנגזרת חייבת להתאפס. זהו תנאי הכרחי, אך התאפסות הנגזרת לבדה עדיין אינה מבטיחה קיצון. כאן הפונקציה גזירה בכל תחום ההגדרה, ולכן נבדוק את הנגזרת:

f′(x) = −9(2x − 5)²

הסבר אפשרי 1 — אין אפסים לנגזרת: שבר שווה לאפס רק כאשר המונה מתאפס. כאן המונה הוא תמיד −9, ולכן המשוואה f′(x) = 0 אינה אפשרית. אין נקודה בתחום ההגדרה שבה מתקיים התנאי ההכרחי לקיצון.

הסבר אפשרי 2 — ירידה בכל תחום: המכנה בריבוע חיובי והמונה שלילי, ולכן הנגזרת שלילית בכל תחום ההגדרה. הפונקציה יורדת בכל אחד משני התחומים, ואינה עוברת מעלייה לירידה או מירידה לעלייה. לכן אין בהם קיצון.

בשני ההסברים יש לזכור: x = 2.5 אינו בתחום ההגדרה, ולכן אינו יכול להיות נקודת קיצון של הפונקציה.

ו תחומי עלייה וירידה

ירידה: x < 2.5 או x > 2.5; אין תחומי עלייה.

פתרון: הנגזרת שלילית בכל תחום ההגדרה, ולכן הפונקציה יורדת בכל אחד משני התחומים.

יש לציין שני תחומי ירידה נפרדים: משמאל לנקודת אי־ההגדרה ומימינה. אין מעבר רציף דרך x = 2.5.

שאלה 3

מעגל ומקבילית במערכת הצירים

שאלה 3 · צמצוםפתיחה

א משוואת המעגל

x² + y² = 25

פתרון: r² = (−4)² + (−3)² = 25. המרכז בראשית, ולכן x² + y² = 25.

משוואת מעגל שמרכזו (a, b) היא (x − a)² + (y − b)² = r². כאן המרכז בראשית, ואת הרדיוס מוצאים באמצעות המרחק מהמרכז לנקודה A.

ב נקודות החיתוך

B = (−3, 4); C = (3, 4)

פתרון: x² + 4² = 25 ⇒ x² = 9 ⇒ x = ±3. שיוך האותיות לפי השרטוט.

לשתי נקודות החיתוך אותו ערך y = 4. שני סימני השורש נותנים שתי נקודות: הנקודה שמשמאל לציר האנכי היא B, והנקודה שמימין היא C.

ג הוכחת מקבילית

ABCD מקבילית.

לנקודות A,D אותו שיעור y = −3, ולכן הצלע AD מקבילה לציר x.

לנקודות B,C אותו שיעור y = 4, ולכן גם הצלע BC מקבילה לציר x. שני ישרים המקבילים לאותו ישר מקבילים זה לזה, ולכן AD ∥ BC.

בקטע המקביל לציר x, האורך הוא ההפרש החיובי בין שיעורי x של הקצוות. לכן:

AD = 2 − (−4) = 6
BC = 3 − (−3) = 6

מצאנו זוג צלעות נגדיות שהן גם מקבילות וגם שוות באורכן. לפי המשפט: מרובע שבו זוג צלעות נגדיות שוות ומקבילות הוא מקבילית. לכן ABCD מקבילית.

ד מיקום הנקודה D

בתוך המעגל.

פתרון: OD² = 2² + (−3)² = 13 < 25 = r², ולכן הנקודה בתוך המעגל.

אפשר להשוות ריבועי מרחקים בלי להוציא שורש, משום שהמרחקים אינם שליליים. בתוך המעגל המרחק מהמרכז קטן מהרדיוס; על המעגל הוא שווה לו, ומחוץ לו הוא גדול ממנו.

ה מפגש האלכסונים

E = (−0.5, 0.5)

פתרון: אלכסוני מקבילית חוצים זה את זה, ולכן E אמצע AC: E = (−4 + 32, −3 + 42) = (−0.5, 0.5). אפשר להשתמש גם באלכסון BD.

נוסחת אמצע קטע היא ממוצע של שיעורי הקצוות בכל ציר בנפרד: x_E = x_A + x_C2 ו־y_E = y_A + y_C2.

שאלה 4

אנך למיתר וטריגונומטריה

שאלה 4 · צמצוםפתיחה

א משוואת האנך

y = −12x + 6

פתרון: מרכז המעגל M = (6, 3). שיפוע הישר הנתון 2, ולכן שיפוע האנך −12. משוואתו y − 3 = −12(x − 6).

במשוואת המעגל קוראים את המרכז מתוך הסוגריים: (x − 6)² + (y − 3)² = 10. מכפלת השיפועים של שני ישרים מאונכים שאינם מקבילים לצירים היא −1, ולכן 2m = −1.

ב נקודת מפגש האנך והמיתר

C = (4, 4)

פתרון: 2x − 4 = −12x + 6 ⇒ x = 4; בהצבה מתקבל y = 4.

הנקודה C נמצאת על שני הישרים ולכן מקיימת את שתי המשוואות. לאחר השוואת הביטויים עבור y מתקבל 2.5x = 10, ומכאן x = 4.

ג חציית המיתר

AC = BC

פתרון: הקטע MC מאונך למיתר ויוצא ממרכז המעגל. אנך ממרכז המעגל למיתר חוצה את המיתר, ולכן AC = BC.

חשוב שמדובר באנך היוצא ממרכז המעגל. זהו התנאי שמאפשר להסיק כי נקודת המפגש עם המיתר היא אמצעו.

ד אורך האנך

MC = √5

פתרון: MC = √((6 − 4)² + (3 − 4)²) = √5.

הפרשי השיעורים בין M ל־C הם 2 בציר האופקי ו־−1 בציר האנכי. לכן ריבוע המרחק הוא 2² + (−1)² = 5.

ה אורך המיתר

AB = 2√5

פתרון: רדיוס המעגל MA = √10. במשולש ישר־הזווית MCA: AC² = MA² − MC² = 10 − 5 = 5. לכן AC = √5 ובהתאם AB = 2AC = 2√5.

הזווית בנקודה C ישרה, ולכן MA הוא היתר. מפיתגורס מחסרים מריבוע היתר את ריבוע הניצב הידוע. לאחר שמוצאים את חצי המיתר, מכפילים ב־2.

ו זווית MAB

∠MAB = 45°

פתרון: הנקודה C נמצאת על AB, ולכן ∠MAB = ∠MAC. מתקיים tan(∠MAC) = MCAC = 1, ולכן הזווית 45°. אפשר גם לזהות משולש ישר־זווית ושווה־שוקיים.

ביחס הטנגנס, MC הוא הניצב שמול הזווית ו־AC הוא הניצב שלידה. שני הניצבים שווים, ולכן זו זווית של 45° במשולש ישר־זווית ושווה־שוקיים.
